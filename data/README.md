# Registry data

`projects.json` is the local authoritative registry for this starter.

The initial seed merges the explicit project list supplied for the Master Project Registry with repository names/URLs extracted from the supplied GitHub hub snapshots. It is intentionally an inventory seed, not a claim that every inferred family/status is final. Use `/admin` to normalize names, families, statuses, summaries, and deployment visibility.

`source-manifest.json` records hashes of source snapshots and design inputs used during the initial build.
